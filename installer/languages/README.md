# Inno Setup translations

`ChineseSimplified.isl` and `ChineseTraditional.isl` are copied from the Inno
Setup source tree:

- https://github.com/jrsoftware/issrc/tree/main/Files/Languages

They are used because the Inno Setup installer does not ship Chinese language
files by default. The remaining languages referenced by `sshpass-win.iss`
(English, Japanese, German, French, Spanish, Russian) are shipped with Inno
Setup itself.
